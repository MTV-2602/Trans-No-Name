## 🌟 Giới thiệu

**Trans No Name** là extension trình duyệt mạnh mẽ, nhẹ nhàng và tối ưu cho nhu cầu dịch thuật hàng ngày khi lướt web, làm việc, học tập và trò chuyện trực tuyến. Extension hỗ trợ dịch hai chiều đa ngôn ngữ, dịch trực tiếp văn bản đang gõ trong ô chat, dịch khi rê chuột (mouseover tooltip), dịch tài liệu PDF, sách điện tử EPUB, phụ đề song ngữ YouTube/Netflix, cũng như nhận diện ký tự hình ảnh (OCR) và giọng nói (Speech).

---

## 🚀 Các tính năng nổi bật

### 1. 💬 Dịch nhanh ô chat (Chat Box Instant Translation)
- **Dịch tức thì trong ô nhập văn bản**: Dịch trực tiếp nội dung bạn đang gõ trong bất kỳ ô nhập liệu nào (`<input>`, `<textarea>`, các trình soạn thảo `contenteditable` của Discord, Facebook Messenger, Telegram Web, WhatsApp, Zalo, Gmail, v.v.).
- **Ghi nhận phím tắt 1 chạm (Click-to-Record Hotkey)**: Không cần chọn menu phức tạp, chỉ cần nhấp chuột vào ô cài đặt phím tắt và bấm bất kỳ phím nào trên bàn phím của bạn (F1–F12, Space, Alt, phím chữ, số, Numpad...) là hệ thống tự động lưu ngay.
- **Nút nổi dịch nhanh (Floating Translate Bubble)**:
  - Tự động xuất hiện nhẹ nhàng cạnh ô chat khi bạn nhấp chuột hoặc gõ chữ vào ô nhập liệu.
  - Nhấp vào nút nổi để dịch tức thì nội dung trong ô mà không cần bấm phím tắt.
  - Tự do kéo thả nút nổi đến bất kỳ vị trí thuận tiện trên màn hình.
  - Nhấp đúp (Double-click) vào nút nổi để đặt lại vị trí mặc định.
- **Tùy biến nút nổi theo phong cách riêng**:
  - **Kích thước**: Nhỏ gọn (28px), Vừa phải (36px), hoặc Lớn (44px).
  - **Màu sắc tự chọn**: Bộ chọn màu (Color Picker) đa dạng, cho phép chọn bất kỳ mã màu yêu thích nào.
  - **Độ trong suốt (Opacity)**: Điều chỉnh từ 30% đến 100% để nút hiển thị tinh tế, không che khuất nội dung trang.
  - **Kiểu hiển thị**: Lựa chọn biểu tượng dịch (`mdi-translate`), icon tròn tối giản, chữ *"Dịch"*, hoặc tự nhập chữ/ký tự riêng của bạn (`writingBubbleCustomText`).

---

### 2. 🔍 Rê chuột dịch tức thì (Mouseover Tooltip)
- **Hover để dịch**: Chỉ cần rê chuột lên từ hoặc đoạn văn bản bất kỳ trên website, tooltip bản dịch sẽ hiển thị mượt mà ngay cạnh con trỏ.
- **Bôi đen dịch (Selection/Highlight)**: Chọn văn bản để hiển thị nghĩa chi tiết hoặc lưu từ vựng.
- **Hỗ trợ phát âm chuẩn (Text-to-Speech)**: Nhấn phím tắt (mặc định `Left Ctrl`) để nghe phát âm từ vựng bằng Google TTS hoặc giọng đọc trình duyệt.
- **Tùy chỉnh giao diện tooltip**: Tùy chỉnh kích thước chữ, font chữ, màu nền tooltip, căn lề và độ rộng hiển thị.

---

### 3. 📄 Dịch tài liệu PDF & Ebook EPUB
- **Trình đọc PDF tích hợp**: Hỗ trợ mở và dịch trực tiếp các file PDF trên máy tính cá nhân hoặc PDF trực tuyến qua thư viện PDF.js tích hợp sẵn.
- **Trình đọc Ebook EPUB**: Hỗ trợ đọc sách điện tử với khả năng dịch nhanh từng câu, từng đoạn và hỗ trợ chế độ đọc ban đêm (Dark Mode).

---

### 4. 🎬 Phụ đề song ngữ Video (Dual Subtitles)
- Tự động hiển thị song ngữ (ngôn ngữ gốc + tiếng Việt/ngôn ngữ đích) cho video trên **YouTube**, **Netflix**, v.v.
- Tự động đồng bộ thời gian và hỗ trợ tùy chỉnh cỡ chữ phụ đề.

---

### 5. 📷 Dịch hình ảnh (OCR) & Giọng nói (Speech)
- **OCR Manga & Hình ảnh**: Giữ phím tắt (mặc định `Left Shift`) và rê chuột qua hình ảnh hoặc trang truyện tranh để tự động nhận diện chữ qua Tesseract OCR và dịch ngay trên ảnh.
- **Bảng dịch giọng nói (Voice Panel)**: Thu âm giọng nói qua microphone và chuyển thành văn bản dịch thời gian thực.

---

### 6. 🌐 Giao diện song ngữ & Thuần Việt
- **Nút chuyển đổi nhanh Tiếng Việt 🇻🇳 / English 🇺🇸**: Đặt trực tiếp ngay góc phải thanh tiêu đề Popup cài đặt. Chuyển đổi toàn bộ ngôn ngữ giao diện chỉ bằng 1 cú nhấp chuột.
- Toàn bộ nội dung tiếng Việt có đầy đủ dấu câu chuẩn, từ ngữ gần gũi, rõ ràng và dễ cấu hình.

## 🛠️ Hướng dẫn cài đặt & Build

### Yêu cầu môi trường
- [Node.js](https://nodejs.org/) (phiên bản 18 trở lên)
- Trình duyệt: Google Chrome, Microsoft Edge, Brave, Cốc Cốc hoặc Mozilla Firefox.

### 1. Cài đặt các thư viện phụ thuộc
```bash
npm install
```

### 2. Build dự án
```bash
# Xóa bản build cũ và build production cho Chrome / Edge / Chromium:
npm run build

# Hoặc bật chế độ theo dõi thay đổi (Watch Mode) khi lập trình:
npm run watch

# Build cho trình duyệt Firefox:
npm run build-firefox
```

Thư mục thành phẩm sau khi biên dịch sẽ nằm tại: `build/`.

### 3. Nạp Extension vào trình duyệt
1. Mở trình duyệt và truy cập trang quản lý tiện ích:
   - Trên **Chrome**: `chrome://extensions/`
   - Trên **Edge**: `edge://extensions/`
   - Trên **Brave**: `brave://extensions/`
2. Bật công tắc **Chế độ dành cho nhà phát triển (Developer mode)** ở góc trên bên phải.
3. Nhấp vào nút **Tải tiện ích đã giải nén (Load unpacked)**.
4. Chọn thư mục `build/` bên trong thư mục dự án này.
5. Biểu tượng **Trans No Name** sẽ xuất hiện trên thanh công cụ của bạn.

```text
├── config/                  # Cấu hình Webpack (common, dev, firefox, paths)
├── public/                  # Tài nguyên tĩnh, manifest, icon và thư viện bên thứ 3
│   ├── _locales/            # File đa ngôn ngữ (50+ ngôn ngữ, bao gồm vi, en,...)
│   ├── doq/                 # Giao diện tài liệu
│   ├── foliate-js/          # Trình đọc sách điện tử EPUB
│   ├── icons/               # Bộ biểu tượng extension
│   ├── pdfjs/               # Bộ hiển thị tài liệu PDF.js
│   ├── tesseract/           # Thư viện nhận diện chữ hình ảnh OCR
│   ├── manifest.json        # Manifest V3 cho trình duyệt Chromium
│   └── manifest.firefox.json# Manifest cho Firefox
├── src/                     # Mã nguồn chính của Extension
│   ├── components/          # Vue components tái sử dụng (popupWindow, backHeader,...)
│   ├── event/               # Xử lý sự kiện (mouseover, selection, writingBubble,...)
│   ├── pages/               # Các trang giao diện Vue (index, saved, history, speech,...)
│   ├── translator/          # Bộ tích hợp các engine dịch thuật (Google, Bing, DeepL, LLM...)
│   ├── tts/                 # Bộ tích hợp phát âm Text-to-Speech
│   ├── subtitle/            # Tự động bắt và chèn phụ đề video
│   ├── util/                # Cài đặt, ngôn ngữ, tiện ích hệ thống
│   ├── background.js        # Service Worker xử lý ngầm (Manifest V3)
│   └── contentScript.js     # Script tiêm vào các trang web
├── package.json             # Cấu hình package, scripts và dependencies
└── README.md                # Tài liệu hướng dẫn sử dụng dự án
```
